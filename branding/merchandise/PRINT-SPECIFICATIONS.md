# Print Specifications

## General

- Color mode: SVG/PDF masters use exact RGB brand values. Convert through the vendor’s documented CMYK profile; request a contract proof for color-critical work.
- Preferred metallic reference: Pantone 871 C when metallic ink/thread is available.
- Raster resolution: 300 DPI at final printed size with alpha transparency.
- Minimum positive line: 1.5 pt for screen print; 2.0 mm stitched feature for embroidery.
- Minimum reversed gap: 2 pt for screen print; 1.5 mm for embroidery.
- Bleed: apparel none; stickers 0.125 in; banners 0.25–0.5 in or vendor template.
- Safe area: apparel 0.25 in; stickers 0.15 in; mug 0.25 in; banner 3 in at final size.

## Embroidery

- Use only `*-embroidery.svg` files.
- One thread color: warm metallic/matte gold matched to `#D4AF37`.
- Suggested maximum: 12,000 stitches for a 3.5 inch chest mark and 8,000 stitches for cap front.
- Underlay, pull compensation, stitch direction, and density must be set by the embroidery digitizer—not inferred from the SVG.
- Remove Bible page-line detail and all gradients; the supplied embroidery files already collapse light areas to gold.
- Request sew-outs on the actual navy/black/white fabric before production.

## Screen print

- Use `*-screen-print.svg` artwork.
- Spot colors: Gold `#D4AF37` and White `#FFFFFF`.
- Use an underbase on navy/black garments. Trap/choke according to the shop’s registration tolerance.
- Recommended mesh: 156–200 for type and symbol; confirm metallic ink requirements with the printer.

## DTG / DTF

- Use `*-dtg.svg` or the matching transparent 300-DPI PNG.
- Enable white underbase on dark garments.
- Preserve Gold and Light Gold as distinct colors; do not apply automatic enhancement or gradients.
- Soft-proof against the chosen garment and order a sample because fabric color affects perceived gold.

## Mug, sticker, and banner

- Mug artwork is a 9 × 3.75 inch wrap; verify handle dead zones on the exact blank.
- Sticker master includes the navy field and gold trim. Add bleed by extending the navy circle/field, never by scaling the logo.
- Conference banner is a proportional 7200 × 3000 master. Scale to the vendor template without changing aspect ratio; reposition only for finishing zones, pole pockets, or grommets.
