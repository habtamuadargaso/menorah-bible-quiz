# Menorah Bible Quiz — Official Merchandise Collection v1.0

Production artwork for the Classic Hoodie, Premium T-shirt, Polo Shirt, Zip Hoodie, Baseball Cap, Coffee Mug, Sticker, and Conference Banner. Application files are not used or modified by this package.

## Brand system

| Role | Color | Use |
|---|---|---|
| Deep Navy | `#0A1E3D` | Garments, fields, premium base |
| Gold | `#D4AF37` | Primary mark and headings |
| Light Gold | `#FFD97A` | DTG accent only |
| White | `#FFFFFF` | Bible pages and supporting type |

Headings use Cinzel Bold; supporting copy uses Poppins. SVG masters retain editable text for production flexibility. Before sending to a vendor, open the selected SVG in Illustrator, Affinity Designer, or Inkscape with Cinzel and Poppins installed and convert text to outlines. Do not substitute or horizontally scale the type.

## File types

- `*.svg`: editable vector master with transparent canvas unless a colored field is intentionally part of the design.
- `*-embroidery.svg`: one-color gold stitch artwork; no gradients or hairline detail.
- `*-screen-print.svg`: reduced two-color gold/white separation.
- `*-dtg.svg`: full approved three-color artwork.
- `*.png`: transparent 300-DPI raster export at the authored print dimensions.
- `*.pdf` and `print.pdf`: vector vendor proof/print PDF at the SVG artboard size.

## Product index

- `hoodie/`: front, back, left sleeve, and right sleeve.
- `tshirt/`: minimal front and two-line back statement.
- `polo/`: left-chest embroidery lockup.
- `zip-hoodie/`: left-chest placement clear of the zipper plus the hoodie back.
- `cap/`: front-panel embroidery symbol.
- `mug/`: full 9 × 3.75 inch wrap.
- `stickers/`: 6 inch round navy-and-gold sticker with built-in border.
- `conference-banner/`: 8 × 3.33 foot proportion master at 7200 × 3000 pixels.
- `mockups/`: visualization only; never send mockup pixels to a printer.

## Vendor handoff

Use the SVG/PDF for Custom Ink, Printful, or Printify whenever the product allows vector uploads. Use PNG only for DTG products that require raster artwork. Verify each vendor template, printable area, safe zone, bleed, garment color, and ink/embroidery pricing before ordering a sample.

Always order a physical pre-production sample. Metallic gold is not represented by the RGB color itself: specify Pantone 871 C or the vendor’s closest metallic thread/ink where supported, otherwise request a physical match to `#D4AF37`.
