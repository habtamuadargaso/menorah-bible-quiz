# Menorah Bible Quiz 1.0.0

Learn Scripture through a premium Bible quiz experience in English and Amharic.

## Version 1.0 includes

- Guided onboarding and a progress-focused Home dashboard
- Solo Quiz with levels, feedback, Scripture references, results, XP, and achievements
- Friends Battle pass-and-play for 2–8 players
- Live Battle online room creation and joining
- Church Mode shared-screen, host-controlled sessions for up to 8 participants
- Leaderboard, Learn, Profile, Settings, Privacy, Terms, and Support
- Signed Android release and verified Android App Links

Daily Challenge and other unreleased discovery features remain hidden for this release. Church Mode is shared-screen only; it does not offer remote joining and does not award personal XP or profile rewards.
