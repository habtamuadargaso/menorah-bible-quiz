# Store Localization Plan

English is the only approved final store-asset language in v1.0. Do not place translated captions or metadata into upload-ready files until a fluent reviewer verifies meaning, capitalization, line breaks, and theological terminology.

For each approved locale, create separate Apple metadata, Google metadata, caption map, phone screenshot set, and—only where maintained—tablet screenshot set. Re-capture actual localized UI rather than translating English pixels.
